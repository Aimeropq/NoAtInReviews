# NoAtInReviews

B站评论过滤油猴脚本：隐藏评论正文中带有真实 @用户提及的整条评论，保留普通 @ 字符和楼中楼的回复前缀。

脚本文件：[`bilibili-hide-mentions.user.js`](./bilibili-hide-mentions.user.js)，版本 `1.0.1`。

## 安装

1. 在已安装 Tampermonkey（油猴）的浏览器中，点击[安装脚本](https://raw.githubusercontent.com/Aimeropq/NoAtInReviews/main/bilibili-hide-mentions.user.js)。
2. 在油猴安装页确认安装，然后刷新已打开的 B站网页。

如果浏览器直接显示源代码，可在油猴菜单中选择“添加新脚本”，用上述文件的全部内容替换默认内容后保存。此前手动安装了 `1.0.0` 的用户，可在原脚本编辑器中替换代码并保存，避免重复安装。

`@downloadURL`（脚本源/下载地址）和 `@updateURL`（更新地址）均指向仓库 `main` 分支中的同一份原始脚本。油猴会按照其更新设置检查脚本的 `@version`；后续发布更新时需要提高版本号。

关闭脚本后刷新页面，即可恢复显示。脚本只改变当前网页的显示，不会删除、举报、拉黑评论或修改账号设置。

油猴的脚本匹配和运行时机说明见[官方文档](https://www.tampermonkey.net/documentation.php?locale=zh)。

## 已确认的过滤规则

| 评论内容 | 结果 |
| --- | --- |
| 正文有真正的用户提及链接，例如 `@某位用户 来看看` | 隐藏整条评论 |
| 普通 `@`、邮箱 `name@example.com`、没有被 B站识别为用户提及的 `@文字` | 保留 |
| 楼中楼只有开头的 `回复 @某位用户：正常正文` | 保留 |
| 楼中楼是 `回复 @甲：来看看 @乙` | 隐藏该条楼中楼 |
| 楼中楼是 `回复 @甲：再次 @甲` | 隐藏该条楼中楼 |
| 主评论是 `回复 @甲：正文` | 隐藏主评论及其全部楼中楼 |
| 主评论没有用户提及，只有某条子回复包含正文提及 | 只隐藏命中的子回复 |
| 作者昵称中有 `@`，正文正常 | 保留 |

不区分被提及的是谁，只要正文有符合规则的用户提及就隐藏。隐藏使用 `display: none !important`，不显示折叠条或提示，不保留该条评论的布局占位。B站自身显示的评论总数、回复总数和分页规则保持原样。

**回复前缀的边界：**B站会将自动回复前缀与正文混在同一段文本中。按已确认的规则，仅豁免楼中楼开头第一段、带冒号的“回复 @用户：”（兼容空格、全角冒号及 `Reply to @user :`）。手动仿写为完全相同格式的开头，也会获得这个豁免。后续出现的用户提及仍参与过滤。主评论没有此前缀豁免。

## 页面范围和实现

- 面向 B站桌面网页版，识别视频、番剧、动态、图文、专栏、个人空间等页面共用的评论组件。
- 适配新版 `bili-comments` 及其多层 open Shadow DOM，同时兼容旧版评论列表和楼中楼结构。
- 监听初始评论、滚动或翻页新增评论、动态弹层及节点复用后的正文变化。对于宿主插入后才创建的 ShadowRoot，最长约 750 毫秒后补充监听。
- 只检查评论正文，不检查动态正文、视频简介、作者昵称、头像、按钮或评论输入框。
- 明确排除 `message.bilibili.com`、`live.bilibili.com` 等消息与直播域名，另外排除播放器、弹幕、私信面板和编辑区域。脚本不在子框架中执行。
- 不读取 Cookie，不保存账号或评论数据，不发出网络请求，不调用模型，不引入外部依赖，不改写网站的 `fetch`、XHR 或 `attachShadow`。

已核对公开视频页的新版评论结构。B站以后更改组件结构或改用 closed Shadow DOM 时，可能需要更新脚本。手机网页和第三方重构的评论组件未专门适配。
